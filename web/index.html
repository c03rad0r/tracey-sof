    How to read this report

    Blockchain facts are outpoints, txids, input/prevout links and values reported by Bitcoin Core. An outpoint → funding transaction edge identifies the transaction that created an output; a transaction → previous output edge identifies an exact spent prevout.

    User evidence consists of purchase records, artifacts, labels and notes. Documentation status and traversal completeness are independent. An incomplete trace never proves that documentation does not exist.

    No ownership inference: this report does not use change detection, common-input ownership, address clustering or similar heuristics. Transaction ancestry does not allocate satoshis within mixed-input transactions.

    Redaction: the privacy control changes the display and SVG export only. The standalone HTML source still contains its embedded report data. Handle the file as sensitive financial information.
